# 🐥 Chicky Voxel (HTML & CSS)

Chicky Voxel is a creative front-end project that builds a cute voxel-style chick using only **HTML and CSS**. The project demonstrates how simple web technologies can be used to create pixel/voxel-inspired 3D visual designs without using images or external libraries.

---

## ✨ Features

- 🐥 Cute voxel-style chick design
- 🎨 Built completely with HTML and CSS
- 📦 No images or frameworks required
- ⚡ Lightweight and fast
- 💡 Great for learning CSS positioning and creative design

---

## 🛠️ Technologies Used

- HTML5
- CSS3

---

## ▶️ How to Run

1. Download or clone the repository
2. Open `index.html` in your browser

No installation or setup required.

This project is created to demonstrate:
